## 🛠️ Технічні вимоги

Сервер повинен бути написаний з використанням express та стартувати на хості та порті, які вказані в змінних оточення HOST та PORT.
Сервер повинен мати ендоінт GET localhost:8000/, який повертає фронтенд сторінку. Це має бути скомпільований React застосунок.

### Фронтенд частина має містити наступні сторінки:

Головна сторінка, яка містить:

Список усіх новин у вигляді карток або таблиці.
При кліку на заголовок або картку новини, користувач має перенаправлятися на сторінку перегляду конкретної новини
Кнопку додавання нової новини.
При кліку на дану кнопку, користувач має перенаправлятися на сторінку створення нової новини
Повний текст самої новини має бути обрізаний і займати не більше трьох рядків тексту, з символом ... в кінці, якщо якась частина тексту була обрізана (ПІДКАЗКА: можете використати CSS властивість line-clamp)

Сторінка з інформацією про конкретну новину, яка містить:

Повний текст новини
Кнопку редагування новини, яка перенапрає користувача на сторінку редагування новини
Кнопка повернення до загального списку новин
Сторінка з формою додавання нової новини чи редагуванням що існує.
Сторінка має містити кнопку підтвердження створення/редагування новини, а також кнопку поверненням до загального списку новин.
Усі сторінки на фронтенді повинні отримувати та передавати дані за допомогою AJAX запитів до API.

Необхідні методи API описані нижче:

Ендпоінт `GET /api/newsposts/`, який повертає список усіх новин. Якщо новин ще немає - він повертає порожній масив. Якщо сталася якась помилка - статус 500.
Ендпоінт `GET /api/newsposts/:id`, який повертає одну новину по переданому id. Якщо новини з таким id не знайдено - повертається статус 404. Якщо сталася якась помилка - статус 500.
Ендпоінт `POST /api/newsposts/`, який створює нову новину, та повертає об'єкт новини із зазначеним id. Якщо сталася якась помилка - статус 500. Дані для нової новини повинні братись з BODY запиту.
Нижче наведений приклад тіла запиту у форматі JSON:

`{
"title": "У зоопарку Чернігова лисичка народила лисеня",
"text": "В Чернігівському заопарку сталася чудова подія! Лисичка на ім'я Руда народила чудове лисенятко! Тож поспішайте навідатись та подивитись на це миле створіння!"
}`

Ендпоінт `PUT /api/newsposts/:id` який змінює одну новину по переданому id, змінюючи дані, які вказані в BODY, і повертає змінений об'єкт новини.
Якщо новини з таким id не знайдено - повертається статус 404.
Якщо сталася якась помилка - статус 500.

Нижче наведений приклад тіла запиту у форматі JSON:
`{
"title": "Маленька лисичка"
}`

Ендпоінт `DELETE /api/newsposts/:id` який видаляє одну новину по переданому id і повертає статус 200.
Якщо новини з таким id не знайдено - повертається статус 404.
Якщо сталася якась помилка - статус 500.
